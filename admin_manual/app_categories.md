# App Categories

## Create new or modify existig ones
Go to `Users Apps` > `App categories`

## Class == Root Category
Example: 'Location Data', 'Helper'

#### Create new Class 
1. Select by mouse click `Virtual Root Category` in `App Categories` on the left side
1. On the right side, in the tab `ADD NEW BELOW` add new class name

#### Modify existig Class
1. Select by mouse click the class (e.g. `Location Data`) on the left side under `App Categories`
1. On the right side go to the tab `RENAME` or `DELETE`

## Categories
Example: 'Clustering', 'Data Access'

#### Create new category
1. Select the class (e.g. `Location Data`) the category should go into on the left side under `App Categories`
1. On the right side, in the tab `ADD NEW BELOW` add new category name
1. Add description by selecting the newly created category on the left side, and than selecting the tab `RENAME`on the right

#### Modify existing categories
1. Select by mouse click the category (e.g. `Location Data`>`Clustering`) on the left side under `App Categories`
1. On the right side go to the tab `RENAME`, `MOVE` or `DELETE`
- `RENAME`: to rename category, add/modify description of the category
- `MOVE`: move category to another class
- `DELETE`: delete category or class
