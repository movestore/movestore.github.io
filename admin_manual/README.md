# MoveApps Admin Manual

This manual covers the work that MoveApps administrators do in the admin area of the
platform: reviewing and building submitted Apps, managing App and Public Workflow
categories, taking in new IO types, and managing users. It is written for the MoveApps
team and is reachable from the admin sidebar in MoveApps.

Everything a user or an App developer needs is in the [User Manual](/).

## Apps

- [Review Apps](/admin_manual/review_apps.md) — what to check on a submitted App before
  building it, and which edits to its Dockerfile are expected
- [Existing Apps](/admin_manual/existing_apps.md) — rebuild an App, find its build logs
  and Dockerfile, change its categories
- [Build `move` Apps](/admin_manual/move1-move2-baseImages.md) — which base image an App
  needs depending on whether it uses `move1` or `move2`
- [Large files in Apps](/admin_manual/large-file.md) — why git-lfs files are ignored, and
  how large provided files reach an App instead
