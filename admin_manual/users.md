# Manage Users
Go to `Users` > `All Users`

### Invitation link
At the bottom of the list of users there is invitation link that is valid for 24h. This is the only way users can get access to `develop` (invitation copied from the user list in develop!)

### User ID
Sometimes the User ID is needed, this can be obtained by clicking on the user which will open the details
